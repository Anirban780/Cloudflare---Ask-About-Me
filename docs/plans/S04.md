# Plan — Slice S4: Infrastructure Bindings & Vectorize

> **Slice:** S4  
> **Goal:** Declare Vectorize index (`ask-about-me-kb`) and Cloudflare Workflows (`ingest-workflow`) bindings in `wrangler.jsonc`, scaffold `IngestWorkflow`, export from Worker entry, update `/api/health` to report binding status, regenerate Wrangler types, and verify gates.  
> **Companions:** `docs/SPECS.md` §4.1, §4.3, §6.4, §9, §15.

---

## 1. Approach

1. **Scaffold `src/workflows/ingest-workflow.ts`**:
   - Import `WorkflowEntrypoint`, `WorkflowEvent`, `WorkflowStep` from `"cloudflare:workers"`.
   - Define payload interface `IngestParams`: `{ docId, title, sourceType, url?, content }`.
   - Implement `IngestWorkflow extends WorkflowEntrypoint<Env, IngestParams>`.
   - Provide minimal valid `run(event, step)` stub with JSDoc comments (full multi-step chunk-embed-upsert will be implemented in Slice S5).
2. **Update `wrangler.jsonc`**:
   - Add `vectorize` binding:
     ```jsonc
     "vectorize": [
       { "binding": "VECTORIZE", "index_name": "ask-about-me-kb" }
     ]
     ```
   - Add `workflows` binding:
     ```jsonc
     "workflows": [
       { "name": "ingest-workflow", "binding": "INGEST_WORKFLOW", "class_name": "IngestWorkflow" }
     ]
     ```
3. **Update `src/server.ts`**:
   - Export `IngestWorkflow` from `./workflows/ingest-workflow` (mandatory for Cloudflare Worker entry).
   - Update `GET /api/health` to report:
     - `ok: true`
     - `agent: "PortfolioAgent"`
     - `model: env.CHAT_MODEL`
     - `retrievalMode: env.RETRIEVAL_MODE`
     - `vectorize: env.VECTORIZE ? "ready" : "unbound"`
     - `workflow: env.INGEST_WORKFLOW ? "ready" : "unbound"`
     - `owner: env.OWNER_NAME`
     - `timestamp: ISO string`
4. **Generate types**:
   - Run `npx wrangler types` to update `worker-configuration.d.ts` with `VECTORIZE: VectorizeIndex` and `INGEST_WORKFLOW: Workflow`.
5. **Verification**:
   - Run `npm test` (all 9 chunker unit tests must remain green).
   - Run `npm run typecheck` (`tsc --noEmit` must pass with 0 errors).

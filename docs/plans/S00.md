# Plan — Slice S0: Baseline Scaffold

> **Slice:** S0  
> **Goal:** Scaffold `cloudflare/agents-starter`, install dependencies, generate types, verify baseline build, record versions in `docs/reference/VERSIONS.md`.  
> **Companions:** `docs/SPECS.md` §15, `docs/SKILLS.md` §1–§3.

---

## 1. Approach

1. Clone or fetch `cloudflare/agents-starter` repository into a temporary staging folder.
2. Carefully copy the starter files (`package.json`, `wrangler.jsonc`, `vite.config.ts`, `tsconfig.json`, `src/`, etc.) into `ask-about-me/` without overwriting existing `docs/`, `PROMPTS.md`, `PROJECT_STEPS.md`, `knowledge/`.
3. Set up `.gitignore` immediately to prevent tracking `.dev.vars`, `.env`, or `node_modules` (per SKILLS.md R8).
4. Run `npm install` inside `ask-about-me/`.
5. Generate types with `npx wrangler types`.
6. Run `npm run typecheck` to verify TypeScript compile is clean.
7. Record installed versions in `docs/reference/VERSIONS.md` (`npm ls agents @cloudflare/ai-chat ai workers-ai-provider wrangler zod`).
8. Verify local dev and baseline deployment readiness.

## 2. Files to Touch

- **New from starter:**
  - `package.json`
  - `wrangler.jsonc`
  - `tsconfig.json`
  - `vite.config.ts`
  - `src/server.ts`
  - `src/app.tsx`
  - `src/client.tsx`
  - `src/styles.css`
  - `index.html` (if provided by starter)
  - `env.d.ts` (generated by wrangler types)
- **Repo configs:**
  - `.gitignore`
  - `.dev.vars.example`
- **Documentation & Tracking:**
  - `docs/reference/VERSIONS.md`
  - `PROJECT_STEPS.md`
  - `PROMPTS.md`

## 3. Risks & Mitigations

| Risk | Mitigation |
|---|---|
| Overwriting custom docs | Clone starter to `/tmp/agents-starter` and copy selectively, keeping `docs/`, `PROMPTS.md`, `PROJECT_STEPS.md` intact. |
| Network issues cloning starter | Try git clone; fallback to tarball download if needed. |
| Missing types / wrangler config mismatch | Run `npx wrangler types` immediately after install. |

## 4. Verification Steps

1. `npx wrangler types` succeeds
2. `npm run typecheck` (or `tsc --noEmit`) passes with 0 errors
3. `docs/reference/VERSIONS.md` populated with exact package versions
4. `git status` shows clean tracking and no secret files

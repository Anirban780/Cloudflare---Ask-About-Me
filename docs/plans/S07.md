## 1. Approach

1. **Guards Module (`src/agent/guards.ts`)**:
   - `decideRate(events: number[], now: number, limit: number, windowMs = 3600000)`:
     - Pure function to evaluate rate limit without database coupling.
     - Drops events older than `now - windowMs`.
     - Rejects when `count >= limit`, calculating `retryAfterSeconds` from the oldest timestamp in the active window.
   - `checkInputLength(text: string, maxChars = MAX_INPUT_CHARS)`:
     - Pure function checking input character ceiling (1,000 characters).
     - Returns friendly user-facing refusal reason when violated.
   - `createStaticUIMessageResponse(text: string)`:
     - Constructs a valid SSE data stream response containing the assistant text delta without calling the LLM.

2. **Unit Tests for Guardrails (`test/guards.test.ts`)**:
   - Boundary tests for `decideRate`:
     - 0 events -> allowed
     - `limit - 1` events -> allowed
     - `limit` events -> rejected with `retryAfterSeconds > 0`
     - Window slide (events older than 1 hour excluded) -> allowed
     - Calculation of retry interval
   - Tests for `checkInputLength`:
     - Exact limit -> ok
     - Below limit -> ok
     - Exceeding limit (1,001 chars, 1,500 chars) -> rejected with clear guidance

3. **Tool `rememberVisitorContext` (`src/agent/tools.ts`)**:
   - Zod schema: `name?: string(≤60)`, `company?: string(≤60)`, `roleHiringFor?: string(≤60)`, `interests?: string[≤5]` (each ≤60).
   - Sanitizes all inputs (trims, strips newlines, caps length).
   - Deduplicates and limits interests to 5 items.
   - Updates `agent.state.visitor` via `ctx.setState()`.
   - Returns `{ saved: true, visitor }`.

4. **Callable RPC `forgetVisitor()` & Lifecycle in `PortfolioAgent` (`src/agent/portfolio-agent.ts`)**:
   - Mark with `@callable()` decorator from `agents`.
   - Resets state to `initialState`.
   - Deletes `retrieval_log` and chat messages in SQLite.
   - Deletes `rate_events` older than 1 hour while preserving the current active window (preventing rate limit bypass through "forget me").
   - In `onChatMessage`:
     - Run rate limit pruning and check via `decideRate`.
     - Run `checkInputLength`.
     - Prune `retrieval_log` rows older than 30 days.

5. **Frontend UI Memory Chip & Privacy Controls (`src/app.tsx`)**:
   - Display memory chip in header/top when `state.visitor` has remembered fields:
     `Remembered: Acme · Solutions Engineer`
   - Include "Forget me" action invoking `agent.call("forgetVisitor")` and `clearHistory()`.
   - Add privacy badge / tooltip: "This site stores only what you tell it, tied to this browser."
   - Display non-blocking banner if rate limit or length guard is tripped.

## 3. Risks & Mitigations

| Risk | Mitigation |
|---|---|
| Abuse via "forgetVisitor" resetting rate limits | `forgetVisitor()` selectively deletes only rate events older than 1 hour, leaving the current hourly window intact. |
| Incompatible decorator syntax for `@callable` | Standard TC39 decorators are configured in tsconfig/package; tested with `tsc --noEmit`. |
| Memory injection via malformed visitor input | `sanitizeField` strips newlines, controls, and enforces 60-char caps in both tool execution and prompt builder. |

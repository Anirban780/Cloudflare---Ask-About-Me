## 1. Approach

1. **Dev Dependencies**:
   - Install `tsx` and `gray-matter` as devDependencies per SKILLS.md R7 allowlist.
   - Add `"ingest": "tsx scripts/ingest.ts"` to `package.json`.
2. **Embedding Helper (`src/rag/embed.ts`)**:
   - Implement `embedTexts(ai: Ai, texts: string[]): Promise<number[][]>` using `@cf/baai/bge-base-en-v1.5` per SPECS.md §4.1 and §6.4.
   - Handle empty inputs and validate output format.
3. **Durable Ingest Workflow (`src/workflows/ingest-workflow.ts`)**:
   - Implement multi-step durable workflow:
     - `validate`: Kebab-case `docId`, required `title` and `content`, 200 KB ceiling.
     - `chunk`: Invokes `chunkMarkdown`, asserts non-empty, checks `<= MAX_CHUNKS_PER_DOC`.
     - `delete-stale`: Deletes pre-existing chunks for `docId` up to `MAX_CHUNKS_PER_DOC` in batches of 100 with retries (limit: 3, delay: 3s, backoff: exponential).
     - `embed-upsert-${i}`: Batches of `EMBED_BATCH_SIZE: 50`. Runs `embedTexts`, maps to Vectorize records with full metadata, and calls `env.VECTORIZE.upsert`. Embed and upsert share a single step to stay within Cloudflare step persistence size limits.
     - `finalize`: Returns `{ docId, chunks, batches, status: "complete" }`.
4. **Admin HTTP Endpoints (`src/server.ts`)**:
   - Constant-time bearer token authentication using `ADMIN_TOKEN`.
   - `POST /api/admin/ingest`: Accepts `{ docs: IngestParams[] }` (up to 1 MB payload), spawns durable workflow instances, returns instance IDs.
   - `GET /api/admin/ingest/:instanceId`: Retrieves workflow execution status.
   - `GET /api/admin/search-debug?q=...&sourceType=...`: Admin evaluation search endpoint running query embedding and Vectorize lookup directly.
5. **Knowledge Base Content (`knowledge/`)**:
   - Create 8 comprehensive documents covering Anirban Sarkar's background, resume, architecture blog, and flagship projects:
     - `knowledge/about.md`: Background, professional philosophy, core stack, contact.
     - `knowledge/resume.md`: Experience history, education, certifications, skills.
     - `knowledge/blog-edge-state-architecture.md`: Technical deep dive on edge state management, Durable Objects, and Vectorize.
     - `knowledge/projects/ask-about-me.md`: This project's architecture, stack, and metrics.
     - `knowledge/projects/cloud-distributed-pipeline.md`: Cloud data and compute pipeline.
     - `knowledge/projects/data-streaming-analytics.md`: Real-time streaming analytics platform.
     - `knowledge/projects/devops-infrastructure-automation.md`: Infrastructure as Code and CI/CD automation.
     - `knowledge/projects/edge-api-gateway.md`: High-performance edge API gateway.
6. **CLI Runner (`scripts/ingest.ts`)**:
   - Scans `knowledge/` recursively for `.md` files.
   - Parses YAML frontmatter with `gray-matter` and validates schema with `zod`.
   - Calls `POST /api/admin/ingest` with Bearer auth.
   - Polls instances until completion and prints a formatted console table summary.

## 3. Risks & Mitigations

| Risk | Mitigation |
|---|---|
| Large vector arrays exceeding Cloudflare step output limits | Embed and upsert within the same step, returning only `{ batchIndex, count }`. |
| Admin token missing in dev environment | Secure constant-time auth check returns 401 if unconfigured or invalid; instructions documented. |
| Duplicate `docId`s in knowledge files | Validation in both CLI script and workflow Step 1 ensures uniqueness and regex format. |

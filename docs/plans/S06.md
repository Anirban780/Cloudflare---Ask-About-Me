# Plan — Slice S6: RAG Tool & Citations

> **Slice:** S6  
> **Goal:** Connect the knowledge base to the persona agent via `searchKnowledgeBase` tool, implement the 7-step pure retrieval algorithm (`src/rag/retrieve.ts`), parse inline `[n]` citations (`src/rag/citations.ts`), render interactive source chips in the chat UI (`src/components/SourceChips.tsx`), and verify with unit tests.  
> **Companions:** `docs/SPECS.md` §6.5, §7, §8.2, §8.3, §8.5, §10, §12.1, §15.

## 1. Approach

1. **Citation Parser (`src/rag/citations.ts`)**:
   - `extractCitationIndices(text: string): number[]`:
     - Parses single `[1]`, adjacent `[1][2]`, comma-separated `[1, 2]`, and whitespace variants.
     - Safely ignores non-citation brackets like `[foo]`, `[]`, `[-1]`, `[0]`.
     - Deduplicates indices while preserving the first appearance order.
   - `matchCitations(text: string, results?: RetrievalItem[])`:
     - Matches extracted indices `n` against `results` where `result.n === n`.
     - Flags unmatched numbers so the UI renders them as plain text without hallucinated sources.

2. **Unit Tests for Citations (`test/citations.test.ts`)**:
   - Test all properties specified in SPECS.md §12.1:
     - Single citations (`[1]`).
     - Adjacent multiple citations (`[1][2]`).
     - Comma-separated citations (`[1, 2]`, `[1,2,3]`).
     - Stray brackets (`[code]`, `[link](url)`, `[]`, `[0]`, `[-5]`).
     - Deduplication of multiple occurrences.
     - Graceful handling of missing/out-of-bound indices.

3. **Retrieval Module (`src/rag/retrieve.ts`)**:
   - Implements pure `retrieve(env, { query, sourceType? })`:
     1. Validate query: 3–300 characters. Return informative note if invalid.
     2. Embed query using Workers AI `@cf/baai/bge-base-en-v1.5` via `embedTexts`.
     3. Query Vectorize: `env.VECTORIZE.query(vector, { topK: TOP_K, returnMetadata: "all", filter })`.
     4. Filter out matches with `score < MIN_SCORE` (0.5).
     5. Enforce `MAX_PER_DOC` (2 per docId), keep highest scores, truncate to `MAX_RESULTS` (5).
     6. Enforce `MAX_CONTEXT_CHARS` (6,000 chars) by trimming from lowest-ranked upward.
     7. Number results `1..n` and return `{ results, note? }`.
     8. Wrap with try/catch to return friendly fallback `{ results: [], note: "Knowledge search is temporarily unavailable." }` on network/service outage.

4. **Unit Tests for Retrieval (`test/retrieve.test.ts`)**:
   - Mock Vectorize and Workers AI bindings to verify:
     - Score filtering at `MIN_SCORE` boundary.
     - Document deduplication at `MAX_PER_DOC` boundary.
     - Result slicing at `MAX_RESULTS`.
     - Context character length trimming at `MAX_CONTEXT_CHARS`.
     - Error resilience when Vectorize fails.

5. **Agent Tools Factory (`src/agent/tools.ts`)**:
   - Implement `buildTools(agent: PortfolioAgent)` returning AI SDK `tool({...})`.
   - `searchKnowledgeBase`:
     - Input schema with Zod: `query` (string 3–300 chars), optional `sourceType` enum.
     - Clear model instructions in description directing Llama 3.3 to search on any factual inquiry.
     - Executes `retrieve` and logs query, count, top score, and doc IDs into SQLite `retrieval_log`.

6. **Durable Object & Prompt Updates**:
   - In `src/agent/portfolio-agent.ts`:
     - Implement `onStart()` to execute DDL for `retrieval_log` and `rate_events`.
     - Wire `buildTools(this)` into `streamText({ tools, stopWhen: stepCountIs(MAX_TOOL_STEPS) })`.
     - Support `RETRIEVAL_MODE === "always"` fallback pre-retrieval.
   - In `src/agent/system-prompt.ts`:
     - Refine grounding rules to explicitly instruct Llama 3.3 to call `searchKnowledgeBase` first for all factual inquiries.

7. **Frontend Source Chips & Tool Indicators (`src/components/SourceChips.tsx`, `src/app.tsx`)**:
   - Create `SourceChips` component rendering clean, accessible citation pills.
   - Expandable on click to view document title, section, relevance score, snippet text, and external link button.
   - Customize tool status in `ToolPartView` to display "Searching Anirban's documents..." during execution.

## 3. Risks & Mitigations

| Risk | Mitigation |
|---|---|
| Llama 3.3 skips tool call and answers from parametric memory | High-emphasis grounding instructions in system prompt, explicit tool description, and support for `RETRIEVAL_MODE="always"` fallback. |
| Model hallucinates citation numbers like `[9]` when only 2 chunks exist | Citation matcher checks against actual tool results; unmapped citations render as harmless plain text. |
| Vectorize query failure in offline/local dev | Graceful fallback returning `{ results: [], note: "..." }` prevents DO crash. |

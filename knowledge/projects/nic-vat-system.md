# VAT Management System — National Informatics Centre (NIC), Tripura

**Period:** June 2025 – July 2025  
**Stack:** Spring Boot (Java), PostgreSQL, RESTful API design  
**Context:** Backend Development Intern at NIC, Tripura  

---

## Project Overview

A state-level VAT (Value Added Tax) management system built for the Government of Tripura, serving **10,000+ registered users** including tax officers and business entities. Anirban was responsible for designing and shipping the backend REST API layer and optimizing the underlying PostgreSQL database schema.

---

## Key Technical Achievements

### RESTful API Development with Spring Boot
- Designed and shipped **10 RESTful APIs** using Spring Boot covering VAT return filing, assessment records, dealer registration, and tax ledger management.
- Applied clean REST design principles: proper HTTP semantics, structured error responses, and request validation at the controller layer.

### PostgreSQL Schema Redesign
- Redesigned the existing PostgreSQL schema to **optimize query execution** — introduced appropriate indexes, normalized redundant columns, and established proper foreign key constraints.
- Improved **data integrity** by adding database-level constraints and triggers to enforce business rules (e.g., preventing duplicate returns for the same assessment period).

- **Backend Framework:** Spring Boot (Java)

- **API Design:** RESTful architecture, proper HTTP semantics
